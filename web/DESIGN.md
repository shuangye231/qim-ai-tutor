# 全能 AI 导师 - Web 桌面端设计规范

> 文档状态：待实现  
> 适用范围：仅 `web/` 桌面端  
> 参考图：`D:\Downloads\ChatGPT Image 2026年7月27日 12_19_39.png`  
> 设计基线：根目录 `PRODUCT.md`、`DESIGN.md`  
> 功能基线：`templates/index.html`、`static/app.css`、`static/app.js`

## 1. 设计目标

### 1.1 核心目标

- 将当前单侧栏聊天页重构为稳定的三栏学习工作台：会话与资料、对话、学习助手。
- 最大化中栏的阅读与连续追问效率，让用户在同一视线范围内完成“提问 -> 理解 -> 沉淀 -> 练习”。
- 对齐参考图的安静、轻量、清晰气质，同时保留现有全部可用功能和真实模型状态。
- 将高频操作常驻，将低频和危险操作收进菜单，降低头部按钮噪声。
- 只使用现有原生 HTML/CSS/JS 技术形态；不因视觉升级引入前端框架或额外组件库。

### 1.2 非目标

- 不把页面做成营销落地页，不增加 Hero、大色块、渐变背景或装饰插画。
- 不把所有功能同时铺成卡片墙；卡片只用于独立、可操作的信息单元。
- 不伪造后端暂未返回的数据，包括“参考来源相关度”“自动保存成功”“连续学习天数”。
- 不在 Web 文档中规定 App 的导航或实现；App 独立以 `app/DESIGN.md` 为准。
- 不修改学习业务、接口协议、模型名称或权限规则。

## 2. 使用场景与设计方向

用户在桌面浏览器中持续学习 AI、RAG 和大模型应用，通常一边阅读长回答，一边管理自己的 Markdown 资料，并把有价值的对话转为路线、笔记和练习。环境以明亮办公或学习桌为主，因此采用低反光的浅色工作台，而不是深色开发者控制台。

创意方向沿用 **The Quiet Study Desk（安静的学习桌）**：

- 中栏像摊开的正文，是视觉主角。
- 左栏像资料夹，负责定位和管理。
- 右栏像学习计划本，展示当前任务和下一步。
- 蓝色只表示当前选择、可执行主动作、进度与焦点。

## 3. 参考图拆解

### 3.1 可直接确认的结构

- 顶部 68px 全宽产品栏，左侧品牌，右侧知识库状态、学习统计、反馈和账号。
- 顶栏下方为三栏：左栏约 272px，中栏自适应，右栏约 368px。
- 左栏依次为：新对话、最近会话、我的资料、上传 Markdown，底部有主题和设备类图标入口。
- 中栏依次为：会话头、滚动消息区、建议追问、固定输入区。
- AI 回答以正文为主，结构化对比使用单个信息面板，而不是一组重复卡片。
- 右栏依次为：学习助手头、四个标签、本周进度、当前路线、下一步、参考来源。
- 表面以白色和极浅冷灰区分，1px 边线承担主要分层，常驻区域无明显投影。

### 3.2 视觉优先级

1. 当前 AI 回答正文。
2. 输入与发送动作。
3. 当前学习路线和下一步。
4. 当前会话、模型和资料状态。
5. 导出、分享、统计、设置等低频工具。

### 3.3 对参考图的必要校正

- 参考图中部分小字对比偏低，实际实现必须达到 WCAG AA。
- 参考图中 RAG / Agent 图标颜色不同；产品仍只保留一个功能蓝色，紫色不得扩展为第二主色。
- “自动保存”只有在本地历史写入成功后显示；保存异常时应明确提示。
- “本次回答参考”只有真实接口数据存在时展示，否则显示可理解的空状态，禁止编造 92% 相关度。

## 4. 桌面信息架构

### 4.1 全局顶栏

- 品牌区：方形“知”标识、产品名“全能 AI 导师”、副标题“你的 AI 学习工作台”。
- 状态区：知识库状态、学习统计、反馈、账号。
- 账号菜单承载：修改密码、学习管理、页面主题、用户头像、AI 头像、退出登录。
- 学习统计打开现有统计视图；反馈打开紧凑反馈浮层。

### 4.2 左侧导航与资料栏

- 主动作：新对话。
- 最近会话：显示当前会话、标题、相对时间；行内悬停后出现重命名和删除。
- 我的资料：内置知识库、已上传的 Markdown、任务工作区。
- 上传入口：支持点击和拖放 `.md` 文件，上传结果进入“已上传的笔记”。
- 低频内容“试试问这些”“提示词模板”不独占长列表，合并到输入区上方的建议追问或空状态。

### 4.3 中央对话区

- 会话头：当前会话标题、保存状态、当前模型；右侧为导出、分享和更多菜单。
- 消息正文：用户消息、AI 回答、回答工具、错误与加载状态。
- 回答工具：朗读保留；导出/分享按会话处理，不重复放到每条回答。
- 回答后的建议追问：解释、对比、应用、练习等 3-4 个上下文动作。
- 会话统计：不再占用固定横条；移入会话头模型状态的详情或“更多”菜单。
- 输入区：聊天/任务模式、任务文件夹、模型、导师模式、附件、语音、文本输入、发送。

### 4.4 右侧学习助手

- 标签：路线、笔记、练习、错题。
- 路线：目标、本周/当前路线进度、路线步骤、下一步动作。
- 笔记：从当前对话生成笔记、笔记列表、阅读视图。
- 练习：当前会话出题开关、生成中、答题、反馈、重新生成。
- 错题：问题、用户答案、复习状态；为空时说明如何产生错题记录。
- 参考来源：仅在接口提供来源时显示真实条目；否则显示“当前回答暂未提供可展开来源”。

## 5. 精确布局规格

### 5.1 应用框架

| 项目 | 规格 |
| --- | --- |
| 页面最小宽度 | 1024px；低于此值进入窄桌面结构 |
| 页面高度 | `100dvh`，禁止固定 75vh 内容卡 |
| 顶栏 | 68px，高度固定，全宽，底部 1px 边线 |
| 主体 | `height: calc(100dvh - 68px)`，CSS Grid |
| 标准三栏 | `272px minmax(520px, 1fr) 368px` |
| 宽屏最大内容 | 1920px 后保持中栏增长；左右栏不继续增长 |
| 分隔方式 | 栏间 1px 边线，不使用卡片间大空隙 |
| 滚动 | 左栏、中栏消息区、右栏内容各自滚动；顶栏与输入区固定 |

### 5.2 左栏

- 宽 272px，内边距 22px 横向、24px 顶部、20px 底部。
- 新对话按钮高 48px，宽度占满，圆角 6px。
- 分组标题 12px/600；标题上间距 26px，下间距 8px。
- 会话行最小高 52px，左右内边距 10px；标题单行省略，时间右对齐。
- 激活会话使用 `primary-soft` 背景和蓝色标题，不使用左侧粗色条。
- 资料行高 58px，可容纳一行标题和一行状态。
- 上传区高 84px，1px 实线边框；拖放时切换蓝色边框与浅蓝底。

### 5.3 中栏

- 会话头高 76px，左右内边距 28px。
- 消息阅读容器最大宽 820px，宽度 `calc(100% - 48px)`，水平居中。
- 消息区上下内边距分别为 34px、24px，消息组间距 28px。
- 用户消息：头像 36px，气泡最大宽 68%，蓝底白字，圆角 8px；不做超大圆角。
- AI 消息：头像 36px；正文不包大白卡，最大行长 72ch，正文 14px/1.75。
- AI 二级标题 15px/700，段前 22px；正文段间 12px；列表项间 6px。
- 结构化对比面板：单外框、8px 圆角；每行左列 220px，右列自适应，行间仅 1px 分隔。
- 建议追问与输入区之间保留 12px；建议按钮高 36px，圆角 6px。
- 输入停靠区左右 24px、下 20px，白底；输入容器最小高 128px，最大高 220px，1px 边线、8px 圆角。
- 文本区最小高 58px，输入文字 14px/1.6；底部工具行高 40px。
- 发送图标按钮 46x46px；发送中替换为停止/加载状态并禁止重复提交。

### 5.4 右栏

- 宽 368px，背景 `canvas`，内边距 22px 24px 24px。
- 头部和标签组成一个连续区域，不嵌套卡片。
- 标签栏高 40px，四等分；选中项蓝底白字、6px 圆角，未选项透明。
- 功能区块用 24px 垂直间距和标题分组；只有“进度”“下一步”“来源”等独立信息单元可用 1px 外框。
- 路线步骤最小高 58px；编号 34x34px；当前项浅蓝底，已完成项用勾选状态，待开始项使用中性灰。
- 学习区按钮宽度随内容，不使用整栏巨大按钮；主动作和次动作保持明确层级。

### 6.1 字体与图标

- 全站单一系统字体族，字距固定为 0，不使用响应式字号。
- 数据使用 `font-variant-numeric: tabular-nums`。
- 图标统一 18-20px、1.75px 描边；实现时优先项目已启用的图标方案，若无库则使用 CSS/文本符号的最小集合，禁止混用 emoji 充当核心控件。
- 纯图标按钮必须有 `aria-label` 与悬停提示；文字按钮只用于明确命令。

### 6.2 表面与阴影

- 常驻三栏无阴影，使用背景层与边线分层。
- 只有菜单、反馈浮层、对话框可用阴影：`0 12px 32px rgba(24, 33, 44, 0.14)`。
- 不使用玻璃拟态、渐变、噪点、光斑或装饰性纹理。

## 7. 组件与完整状态

所有交互组件至少覆盖以下状态：默认、悬停、键盘焦点、按下、禁用、加载、错误；选项类组件还需覆盖选中。

| 组件 | 状态要求 |
| --- | --- |
| 主按钮 | 默认蓝底；悬停深一阶；按下再深一阶；焦点 3px 环；禁用 40% 不透明且不可点；加载保留原宽度 |
| 次按钮/图标按钮 | 默认透明；悬停浅灰或浅蓝；按下中性深一阶；危险动作只在菜单内使用红色 |
| 会话行 | 默认、悬停、当前选中、重命名输入、删除待确认；重命名 Enter 保存、Esc 取消 |
| 菜单 | 触发器展开态、键盘上下移动、Esc 关闭、点击外部关闭；不得被滚动容器裁切 |
| 标签 | 默认、悬停、选中、焦点、禁用；使用正确 `tablist/tab/tabpanel` 语义 |
| 输入框 | 空、输入、聚焦、多行增长、禁用、发送中、接口失败；错误在输入附近说明下一步 |
| 文件上传 | 默认、悬停、拖入、校验失败、上传中、成功、网络失败；只接受 `.md` |
| 模型选择 | 当前真实模型、切换中、切换成功、切换失败回滚；可见状态必须与 `/api/models` 一致 |
| AI 回答 | 骨架/分阶段加载、正常 Markdown、代码块、朗读中、模型不可用、网络错误 |
| 学习路线 | 未登录、空目标、生成中、已生成、步骤完成/当前/待办、保存失败 |
| 笔记 | 空、生成中、列表、阅读、删除确认、错误 |
| 练习 | 未生成、生成中、答题、提交中、反馈、重新生成、错误 |
| 错题 | 空、列表、标记掌握、加载、错误 |
| Toast | 成功、错误、提示；不放 emoji；重要错误同时保留在相关组件内，不能只闪 3 秒 |
| 对话框 | 打开后聚焦首个控件、焦点圈闭、Esc 关闭、关闭后焦点回触发器；危险操作有明确后果 |

### 7.1 动效

- 常规悬停和状态切换 150-200ms，只改变颜色、透明度或轻微位移。
- 不做页面入场编排，不给所有列表逐项飞入。
- 加载使用与内容形状一致的骨架或现有阶段提示，不在空白中央放孤立转圈。
- `prefers-reduced-motion: reduce` 下取消位移、循环轨道与平滑滚动，只保留即时状态切换。

## 9. 窄桌面响应边界

响应式只针对 Web 桌面/平板横屏，不替代独立 App。

| 宽度 | 结构 |
| --- | --- |
| `>= 1440px` | 完整三栏：272px / 自适应 / 368px |
| `1200-1439px` | 左栏 248px，右栏 336px；中栏仍不低于 520px |
| `1024-1199px` | 左栏折叠为 72px 图标栏；右栏 320px；会话历史用浮层展开 |
| `< 1024px` | Web 进入降级模式：右侧学习助手收为可打开侧面板；不声明为 App 布局 |

- 任何宽度都不得缩放字体。
- 中栏小于 520px 前必须先折叠辅助栏。
- 固定工具栏和输入框不得遮挡正文最后一行。
- 1024px 是本 Web 实现的正式验收下限；手机交互由独立 `app/` 实现负责。

## 10. 可访问性与键盘

- 正文/背景对比度至少 4.5:1，大文本至少 3:1；占位文字同样达到 4.5:1。
- 页面首个可聚焦元素提供“跳到对话内容”的隐藏链接。
- 三栏使用 `nav/main/aside` 语义；每个区域有可访问名称。
- 所有图标按钮提供中文 `aria-label`，状态按钮同步 `aria-expanded`、`aria-selected`、`aria-pressed` 或 `aria-busy`。
- 会话、模型、导师模式、标签、菜单和对话框均可只用键盘完成。
- 消息加载和提交结果使用适度的 `aria-live`；禁止让逐字内容持续打断读屏。
- 焦点样式不依赖颜色之外的微弱变化；保持 3px 可见焦点环。
- 点击目标桌面端不小于 36x36px；关键图标按钮使用 40x40px。
- Markdown 标题保持顺序，代码块可横向滚动并提供复制按钮的可访问名称。

## 13. 实施优先级

1. 建立独立 `web/` 页面结构和共享 tokens，先完成三栏骨架。
2. 迁移会话、消息、输入与模型的核心链路，确保可真实提问。
3. 迁移上传、任务工作区、导出、分享、统计与账号工具。
4. 将学习助手从浮动抽屉变为右栏常驻标签面板。
5. 补齐状态、可访问性、窄桌面规则和视觉验收。

此顺序仅用于 Web 实现；Web 完成并验收前，不开始 App 代码。

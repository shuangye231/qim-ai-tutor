# 启码 AI 学伴部署与使用手册

## 一、交付范围

本版本适用于全新 Ubuntu 24.x86_64 服务器，采用 Docker Compose 一键部署。

主要功能：

- 学生注册、登录、密码修改、头像和账号管理
- AI 学习导师：连续对话、学习模式、学习路线、笔记、练习、错题本、复习提醒和周报
- RAG 知识库：上传 Markdown、文本、Office、PDF 等资料，基于资料问答
- 教师/机构：机构代码、班级、成员、班级聊天、资料和 AI 练习草稿
- 作业中心：作业发布、Scratch 作品提交、教师查看和评分
- OJ 题库：Python/C++ 代码运行、题目练习、进度和排行榜
- 编程竞赛：题目导入/生成、发布、答题、提交、排行榜和教师分析
- Scratch 3：浏览器内编辑、自动保存、导出和提交作品
- 管理接口：机构、账号、额度、AI 配置和基础统计

交付包已保留前端插图源文件 `web/src/assets/` 和 Scratch 3 运行所需源码；`web/dist/` 会在 Docker 构建时自动生成，不能将其作为手工维护目录。

## 二、甲方服务器准备

安装脚本会自动执行以下检查：

1. 检查操作系统是否为 Ubuntu。
2. 检查 CPU 架构是否为 `amd64`，即 x86_64。
3. 检查 Docker Engine；没有则安装。
4. 检查 Docker Compose 插件；没有则安装。
5. 启用并启动 Docker 服务。

甲方需要准备：

- 一台能 24 小时运行的 Ubuntu 服务器
- 至少一个可用的服务器内网/公网 IP
- 服务器可以访问 Docker Hub、Python 包源和 AI API 服务
- 若需要外网访问，准备域名、DNS 解析和 HTTPS 证书
- 若需要 C++ OJ，服务器必须允许 Docker 拉取并运行代码执行镜像

MySQL 不是本版本的运行前置条件。当前业务代码和表结构使用 SQLite；为了不改变已经测试好的业务代码，本交付版不做数据库迁移。`data/app.db` 会在首次启动时自动创建，交付时不带任何数据。

## 三、一键安装

```bash
cd /path/to/启码AI学伴-Linux交付版
chmod +x scripts/install_ubuntu.sh scripts/backup.sh
./scripts/install_ubuntu.sh
```

安装时：

- 管理员密钥由甲方输入；留空则自动生成，终端会显示一次生成结果，请保存。
- AI API Key 由甲方输入，不会回显；留空时 AI 功能暂不可用，后续可编辑 `.env`。
- AI Base URL 默认是 `https://api.ccode.vip/v1`，使用其他 OpenAI 兼容服务时改成对应地址。
- 首次构建会安装 Python/Node 依赖并下载 Embedding 模型，耗时取决于网络和服务器配置。

启动后访问：

```text
http://服务器IP:8899
```

健康检查：

```bash
curl http://127.0.0.1:8899/api/health
```

## 四、AI 配置

`.env` 只存在于甲方服务器，不上传 GitHub。常用配置：

```dotenv
ADMIN_API_KEY=甲方自行设置的管理员密钥
PRO_API_KEY=甲方AI服务密钥
CCODE_API_KEY=
CLOUD_BASE_URL=https://api.ccode.vip/v1
HF_OFFLINE=0
```

修改后重启：

```bash
docker compose up -d
```

AI 功能依赖 `PRO_API_KEY` 或 `CCODE_API_KEY`。密钥不要写入前端代码、截图、日志或 GitHub。管理员接口使用请求头 `X-Admin-Key`，管理员密钥不要分享给普通用户。

首次成功下载 Embedding 模型后，如需离线启动，可将 `HF_OFFLINE=1` 后重启；不要在模型尚未下载完成时设置为 `1`。

## 五、运行与更新

```bash
docker compose ps
docker compose logs --tail 200 tutor
docker compose restart tutor
docker compose up -d --build
```

更新代码前先备份 `data/` 和 `static/`。Compose 配置使用 `restart: unless-stopped`，服务器重启后 Docker 会自动拉起服务。

## 六、数据与备份

运行数据目录：

- `data/`：SQLite 数据库、上传资料、反馈、工作区
- `static/`：头像、班级媒体、Scratch/作业提交等可变文件
- `.hf-cache/`：Embedding 模型缓存
- `.env`：管理员和 AI 配置，禁止上传

备份：

```bash
./scripts/backup.sh
```

建议将 `backups/` 复制到另一台机器或独立磁盘，并定期演练恢复。恢复时停止服务，将备份中的 `data/` 和 `static/` 覆盖回项目目录，再执行 `docker compose up -d`。

## 七、外网与 HTTPS

开发/内网访问可直接使用 `8899`。正式公网访问建议：

1. 使用 Nginx 或 Caddy 反向代理到 `127.0.0.1:8899`。
2. 只对外开放 `80/443`，不要直接开放 `8899`。
3. 配置 HTTPS、域名和自动续期。
4. 使用防火墙限制 SSH 来源，并关闭不需要的端口。

Caddy 示例：

```caddyfile
tutor.example.com {
    reverse_proxy 127.0.0.1:8899
}
```

## 八、API 调用说明

FastAPI 在线接口文档：

```text
http://服务器IP:8899/docs
```

常用接口：

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/api/health` | 健康检查 |
| `POST` | `/api/register` | 注册学生账号 |
| `POST` | `/api/login` | 登录并取得会话令牌 |
| `POST` | `/api/ask` | AI 学习导师问答 |
| `POST` | `/api/upload` | 上传知识库资料 |
| `GET` | `/api/knowledge/files/{username}` | 查看本人资料 |
| `GET` | `/api/models` | 查看模型配置 |
| `GET` | `/api/stats` | 查看个人统计 |
| `POST` | `/api/clear` | 清除会话 |
| `POST` | `/api/compiler/run` | 运行代码 |
| `POST` | `/api/oj/submit` | 提交 OJ 题目 |
| `GET` | `/api/courses/{course_id}/progress/{username}` | 查看课程进度 |
| `GET` | `/api/assignments` | 查看作业 |
| `GET` | `/api/classes` | 查看班级 |
| `GET` | `/api/contests` | 查看竞赛 |

登录后把返回的会话令牌放入请求头：

```bash
curl -X POST http://127.0.0.1:8899/api/ask \
  -H 'Content-Type: application/json' \
  -H 'X-Session-Token: 登录返回的令牌' \
  -d '{"username":"student01","query":"什么是变量？","session_id":"main"}'
```

不同接口需要的字段请以 `/docs` 为准。对外开放 API 前必须增加 HTTPS、访问频率限制和调用方身份校验。

## 九、管理员使用

管理员密钥只用于 `/api/admin/*` 接口，例如：

```bash
curl http://127.0.0.1:8899/api/admin/overview \
  -H 'X-Admin-Key: 甲方设置的管理员密钥'
```

系统中的教师、学生账号通过页面创建或由教师流程管理。管理员密钥不是普通用户登录密码；请保存到密码管理器，不要写进 README。

## 十、上线前必须确认

- 已填写有效 AI API Key，并确认额度、计费和地域合规要求。
- 已设置强管理员密钥，并限制服务器 SSH 登录。
- 已完成域名、HTTPS、防火墙和备份策略。
- 已设置磁盘监控；模型、上传资料和代码提交会占用磁盘。
- OJ 会通过 Docker 运行代码镜像；交付 Compose 会挂载 Docker socket，这是为了支持代码执行，必须把服务器和项目目录限制为可信管理员使用。
- 当前支付仍是模拟支付，不能直接作为正式收费系统使用。
- 当前数据库仍是 SQLite，适合本交付版本的小规模单机部署；高并发或多机构正式商用前应单独进行数据库迁移和安全评估。

## 十一、故障排查

```bash
docker compose ps
docker compose logs --tail 200 tutor
nc -zv 127.0.0.1 8899
curl http://127.0.0.1:8899/api/health
```

常见情况：

- AI 调用失败：检查 `.env` 的 API Key、Base URL、服务器网络和服务商额度。
- 首次启动慢：Embedding 模型正在下载，查看 `docker compose logs -f tutor`。
- C++ 无法提交：检查 Docker 服务、`gcc:14-bookworm` 镜像和 Docker socket 挂载。
- 数据丢失风险：确认 `data/`、`static/` 是 Compose 挂载目录，并按计划执行备份。

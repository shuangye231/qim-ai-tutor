# C++ 编程与算法启蒙路线

## 第一阶段：基本输入输出

- 认识程序入口 `main`。
- 使用 `cout` 输出结果，使用 `cin` 读取输入。
- 认识 `int`、`double`、`char`、`bool` 和 `string`。
- 练习：读取两个整数并输出它们的和、差与乘积。

## 第二阶段：条件与循环

- 使用 `if`、`else if`、`else` 处理分支。
- 使用 `for` 完成次数明确的循环。
- 使用 `while` 完成由条件控制的循环。
- 练习：判断闰年、计算累加和、打印简单图形。

## 第三阶段：数组、字符串和函数

- 使用数组保存一组同类型数据。
- 遍历数组，求最大值、最小值和平均值。
- 处理字符串长度、字符和简单拼接。
- 使用函数拆分问题，理解参数和返回值。

## 第四阶段：算法启蒙

- 枚举：把可能情况有顺序地尝试一遍。
- 模拟：按照题目规则一步一步执行。
- 排序：理解数据从小到大的排列过程。
- 二分查找：在有序数据中不断缩小查找范围。

## 做题步骤

1. 圈出输入、输出和数据范围。
2. 用一个小例子手算过程。
3. 把手算步骤翻译成变量、判断和循环。
4. 用普通情况、边界情况和特殊情况分别测试。

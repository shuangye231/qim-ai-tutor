# Scratch 创意编程学习路线

## 适合谁

适合刚开始接触编程、希望用动画和游戏理解程序逻辑的孩子。学习时先观察效果，再搭积木验证，不要求背诵。

## 第一阶段：认识舞台和角色

- 认识舞台、角色、造型和声音。
- 使用“当绿旗被点击”启动程序。
- 使用移动、旋转和坐标积木改变角色位置。
- 小作品：让角色完成一段自我介绍。

## 第二阶段：顺序、循环和判断

- 顺序结构：积木按从上到下的顺序运行。
- 循环结构：重复执行相同动作，减少重复积木。
- 判断结构：根据条件决定是否执行某段程序。
- 小作品：制作会自动巡逻并躲避障碍的角色。

## 第三阶段：变量、消息和克隆

- 用变量记录分数、时间和生命值。
- 用广播消息让多个角色互相配合。
- 用克隆生成多个相似角色，并分别控制它们。
- 综合作品：完成一个带计分、倒计时和结束画面的小游戏。

## 调试方法

1. 先说清楚“希望发生什么”和“实际发生什么”。
2. 每次只检查一小段积木。
3. 给关键变量勾选舞台显示，观察数值是否正确。
4. 修改后重新点击绿旗，从头验证。

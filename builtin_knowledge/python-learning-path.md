# Python 少儿编程学习路线

## 第一阶段：让程序和我对话

- 使用 `print()` 输出文字。
- 使用 `input()` 获取用户输入。
- 认识字符串、整数和浮点数。
- 小作品：制作一个会打招呼的自我介绍程序。

## 第二阶段：让程序做选择和重复工作

- 使用 `if`、`elif`、`else` 表达条件。
- 使用 `for` 遍历一组数据。
- 使用 `while` 在条件成立时重复执行。
- 小作品：完成猜数字游戏，并记录猜测次数。

## 第三阶段：整理数据和代码

- 使用列表保存一组相关数据。
- 使用字典保存名称和值的对应关系。
- 使用函数把重复步骤封装起来。
- 理解参数、返回值和局部变量。
- 小作品：完成一个可以添加、查看和完成任务的清单程序。

## 第四阶段：项目练习

- 文字冒险：练习输入、判断和函数。
- 成绩统计：练习列表、循环和简单计算。
- Turtle 绘图：练习坐标、循环和函数。

## 调试方法

读报错时先看最后一行的错误类型，再看提示的行号。修改一个问题后重新运行，不要一次改很多地方。可以在关键位置临时加入 `print()`，观察变量的实际值。
